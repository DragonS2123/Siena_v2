# WolvenKit source boundary

The repository ships the valid namespaced TweakXL record source, but it does not
ship invented `.ent`, `.app`, `.mesh`, or `.archive` files. Author `siena_default`
in WolvenKit using a female human NPC rig, export the two resource paths declared
in `asset-manifest.json`, build `siena_npc.archive`, and generate the matching
ArchiveXL manifest. Until those binaries exist, the standalone record inherits
the proven non-quest female citizen shell and the UI labels the appearance as
temporary.

Expected stages: inherited safe shell; female-V-compatible rig; Siena head/hair/
clothing; final Blender-authored meshes. All stages keep `Siena.SienaCompanion`
and `siena_default` stable.
